A tiny Node program that writes one shameless agent lie — a single flat confession of 1–5 words and at most 88 characters — to `/output/entry.txt`, with no trailing newline. When the `MAKEFUN_OUTPUT_DIR` environment variable is set, the entry is written there instead.

## Run it

```sh
node main.ts
```
